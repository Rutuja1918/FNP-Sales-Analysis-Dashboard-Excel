FNP Sales Analysis Dashboard

Project Overview

An Excel-based sales analytics project designed to analyze revenue trends, product performance, order patterns, and delivery metrics using interactive visualizations.

Objectives

Track key sales performance indicators.

Analyze revenue by occasion, product category, and month.

Identify top-performing products.

Examine order distribution across cities.

Evaluate average order-to-delivery time.

Key Insights

Anniversary orders generate the highest revenue among the displayed occasion groupings.

Soft Toys are the leading revenue-generating category among the displayed categories.

Revenue varies across months, indicating patterns worth further investigation.

Product-level analysis highlights the highest-revenue products.
